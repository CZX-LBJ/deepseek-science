# 评测科研任务质量

[English](science-evaluation.md) | 中文

目标是改进通用科研与 AI/计算机工作流。内嵌技能数量、离线回放和合成数据图都不能证明产品优越性。[Claude Science 官方产品说明](https://www.anthropic.com/news/claude-science-ai-workbench)仅作为功能参考，不是此工作区已测量的基线。

## 准备公平的比较

使用一致的任务说明、论文、数据、成果要求、访问权限与停止预算。用哈希固定输入，保留确切模型/版本、工具配置、提示词、原始输出、失败与人工干预。两个开放系统都支持相同模型和工具时，可采用相同设置来研究 harness 的贡献。闭源产品可能无法控制这些条件；应将其标为产品比较，并记录模型与工具差异。

## 检查可观察成果

| 任务 | 必需结果 | 拒绝或扣分项 |
|---|---|---|
| 文献综述 | 相关论文、真实书目标识、阅读深度与证据定位 | 虚构引用、把摘要当成全文阅读、把来源故障当成没有论文 |
| 选题与查新 | 已有工作比较、可检验计划与有范围限制的论断 | 无依据的创新性、不可检验假设、遗漏可比工作 |
| 分析与绘图 | 正确计算、采样单位、标注的不确定性、保留输入与可执行制图代码 | 修改原始数据、误导的误差条、超出设计的因果论断 |
| 写作与修改 | 数值论断关联真实结果、已核验引用键与检查过的输出 | 无依据数值、虚构引用、把未解决缺口当成已完成工作 |
| 输入变化 | 变化使依赖结果失效，并可重新核验 | 保留过时的完成状态、把旧图当成新结果 |
| 中断工作 | 可检查的恢复，保留已完成工作且不重复外部操作 | 丢失状态、重复提交任务、未报告部分失败 |

相关性、创新性和科学支持应交给独立领域评审；可行时隐藏产品名称。机械检查验证文件存在、算术、书目信息与可复现性，科学语义判断另外处理。完成率须包含失败和缺依赖的运行。

## 在质量之后比较效率

多次试验报告任务完成率、实质错误率、可复现性、人工干预、墙钟时间和可获取的总费用。保留成功、失败与重试请求。区分 API 用量、订阅与计算资源费用，不把未知价格记为零。缓存占比须依据真实提供商用量及一致的输入分桶。[基准测试指南](../../cookbook/benchmarking-science.zh.md)定义可执行的本地基线比较；小型合成任务不能证明整体科研质量。

真实评测需要配置 DeepSeek 凭据并能访问对照产品。此工作区尚未执行闭源产品对照。结果产生前，较低成本、更好的恢复和更高任务质量都属于待验证目标。
