# DeepSeek Science 0.2.1-alpha.1（中文）

[English](0.2.1-alpha.1.md) | 中文

这是基于 DeepSeek Harness 桌面运行时构建的 Windows x64 独立科研工作台预览版。

## 包含内容

- 可配置 DeepSeek 和兼容自定义模型的模型设置页面。
- 自动路由至 968 项经过校验的科研技能与参考资料，其中包含 22 个可调用的 Nature Skills 工作流及共享资源。
- 文献检索、选题、研究设计、数据分析、学术绘图、LaTeX 论文起草与审阅支持。
- 完整的 Windows 安装包，包含应用运行时和科研资源；不包含 API 密钥或用户工作区。
- 中英文安装说明、上游来源归属和内嵌资源许可说明。

## 安装

从本 Release 下载 `DeepSeek-Science-Setup-0.2.1-alpha.1.exe` 并按提示安装。在应用 **设置 → 模型** 中配置模型。安装程序未签名，Windows 可能显示 SmartScreen 提示；安装前请核对同目录的 `.sha256` 文件。

应用日常工作流所需的 Node.js 和 Python 已内置。需要在本机编译 PDF 时，请另外安装 MiKTeX 或 TeX Live 等 TeX 发行版。模型调用和外部服务可能产生服务商费用。

## 范围与限制

这是面向 Windows x64 的早期预览版，本次未打包其他操作系统。研究者仍需核实来源、方法、结果、图表和引用；agent 不保证选题新颖、科学结论有效或期刊录用。

Harness 代码和 DeepSeek Science 改动采用 MIT 许可。内嵌第三方资料保留各自许可；`academic-research-skills` 与 `academic-research-skills-codex` 资源包单独隔离、默认关闭，并受 CC BY-NC 4.0 约束。
