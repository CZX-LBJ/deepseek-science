# DeepSeek Science 0.2.1-alpha.2

English | [中文](0.2.1-alpha.2.zh.md)

## Changes

- Publishes all 11,527 hash-pinned scientific resources in the source repository, including files omitted by broad ignore rules in alpha.1. The scientific library contains 968 catalog entries from 19 sources.
- Adds a complete source inventory and explains default discovery, automatic routing, invocation restrictions and external setup requirements. Catalog size is not a count of end-to-end validated scientific capabilities.
- Removes generated build-path comments, Python bytecode and local installer metadata from the application. FontTools console commands now use a relative bundled Python launcher.
- Adds unpacked application checks for credential bytes and build/profile paths, including binary UTF-16 strings. Source publication also checks every declared resource against the Git index and its pinned hash.

## Install

Download `DeepSeek-Science-Setup-0.2.1-alpha.2.exe` and its `.sha256` file from this release. Verify the checksum, run the installer, and configure your own provider under **Settings → Models**. This is an unsigned Windows x64 preview. Node.js and Python are bundled; local PDF compilation needs a separate TeX installation.

## Validation

The official build, scientific resource verification and source completeness check passed. Focused desktop startup, product, portable-copy, privacy and source-publication tests passed (128 tests, one skipped). Changed TypeScript tests passed lint; packaging scripts passed syntax and behavior checks. The prepared application passes runtime integrity and scientific-profile startup checks; the release archive is unpacked and checked again before publication.

## Limitations

The library retains 57 guidance-only entries, 910 entries marked needs-setup and one shared support entry. Upstream workflows and external scientific software have not all been executed in this application. The two noncommercial research packs remain disabled by default. Repository-wide documentation and lint checks are not all passing; the earlier full desktop run also had eight Windows upload-test failures under local PowerShell signing policy. This release does not certify scientific validity or journal readiness.
