# DeepSeek Science 0.2.1-alpha.1

This prerelease introduces a standalone Windows x64 research workbench built on the DeepSeek Harness desktop runtime.

## Included

- A configurable model provider screen for DeepSeek and compatible custom endpoints.
- Automatic routing across 968 verified scientific skill and reference entries, with 22 callable Nature Skills workflows and shared resources.
- Research support for literature discovery, idea development, study planning, analysis, scientific plotting, LaTeX manuscript drafting, and review.
- A self-contained Windows installer that includes the application runtime and research resources. API credentials and user workspaces are not included.
- English and Simplified Chinese documentation, including installation steps, source attribution, and bundled-license notes.

## Install

Download `DeepSeek-Science-Setup-0.2.1-alpha.1.exe` from this release, run it, and follow the prompts. Configure your provider under **Settings → Models**. The installer is unsigned, so Windows may display a SmartScreen warning. Verify the adjacent `.sha256` file before installing.

Node.js and Python are bundled for the app's ordinary workflows. Install a TeX distribution such as MiKTeX or TeX Live if you need local PDF compilation. Model usage and external services may incur charges from their providers.

## Scope and limitations

This is an early preview for Windows x64. Other operating systems are not packaged in this release. The agent can assist with research and manuscript preparation, but researchers must verify sources, methods, results, figures, and citations. It cannot guarantee novelty, scientific validity, or journal acceptance.

The Harness code and DeepSeek Science changes use MIT terms. Embedded third-party materials retain their own licenses; in particular, the isolated `academic-research-skills` and `academic-research-skills-codex` packs are CC BY-NC 4.0 and disabled by default.

# DeepSeek Science 0.2.1-alpha.1（中文）

这是基于 DeepSeek Harness 桌面运行时构建的 Windows x64 独立科研工作台预览版。

## 包含内容

- 可配置 DeepSeek 和兼容自定义模型的模型设置页面。
- 自动路由至 968 项经过校验的科研技能与参考资料，其中包含 22 个可调用的 Nature Skills 工作流及共享资源。

- 完整的 Windows 安装包，包含应用运行时和科研资源；不包含 API 密钥或用户工作区。
- 中英文安装说明、上游来源归属和内嵌资源许可说明。

从本 Release 下载 `DeepSeek-Science-Setup-0.2.1-alpha.1.exe` 并按提示安装。在应用 **设置 → 模型** 中配置模型。安装程序未签名，Windows 可能显示 SmartScreen 提示；安装前请核对同目录的 `.sha256` 文件。

应用日常工作流所需的 Node.js 和 Python 已内置。需要在本机编译 PDF 时，请另外安装 MiKTeX 或 TeX Live 等 TeX 发行版。模型调用和外部服务可能产生服务商费用。
