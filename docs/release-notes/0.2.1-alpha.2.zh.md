# DeepSeek Science 0.2.1-alpha.2

[English](0.2.1-alpha.2.md) | 中文

## 改动

- 将全部 11,527 个固定哈希的科研资源纳入公开源码，包括 alpha.1 中被过宽忽略规则遗漏的文件。科研库包含 19 个来源的 968 项目录条目。
- 添加完整来源清单，说明默认发现范围、自动路由、调用限制与外部运行条件。目录数量不代表已经端到端验证的科研能力数量。
- 清理应用中的构建路径注释、Python 字节码和本地安装元数据。FontTools 命令改用相对路径启动内置 Python。
- 新增解包后应用的凭据、构建目录和用户目录扫描，涵盖二进制 UTF-16 字符串。源码发布还会对照 Git 索引和固定哈希，核验每一个声明资源。

## 安装

从本 Release 下载 `DeepSeek-Science-Setup-0.2.1-alpha.2.exe` 及其 `.sha256` 文件。核对校验值后运行安装包，在 **设置 → 模型** 中配置自己的服务商。本次是未签名的 Windows x64 预览版。Node.js 与 Python 已内置；本机编译 PDF 需要另外安装 TeX。

## 验证

完整构建、科研资源校验和源码完整性检查通过。桌面启动、产品、便携复制、隐私及源码发布的定向测试通过（128 项通过，1 项跳过），修改的 TypeScript 测试文件通过 lint，打包脚本通过语法及行为检查。准备好的应用通过运行时完整性和科研配置启动检查；发布归档会在公开前再次解包核验。

## 限制

库中保留 57 项 guidance-only、910 项 needs-setup 和 1 项共享支持条目；并非全部上游流程和外部科研软件都已在本应用中执行验证。两个非商业科研包仍默认关闭。仓库级文档与 lint 检查尚未全部通过；此前完整桌面测试还有 8 项 Windows 上传测试因本机 PowerShell 签名策略失败。本次发布不代表科学结论有效或稿件已达到期刊标准。
