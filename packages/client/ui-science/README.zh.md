# @deepseek-ai/dsh-client-ui-science

[English](README.md) | 中文

## 概述

科研侧边栏展示研究项目已记录的阶段、成果与证据、检索到的论文、阅读摘录、技能可用状态和模型实际用量。它读取宿主的科研会话投影，并明确显示缺失的计量值。

<a id="use-this-package"></a>
## 使用本包

将本浏览器插件与现有右侧边栏、语言和会话适配器、生成的技能 Remote 及宿主科研工具一起组合。从右侧边栏导航页打开“科研”。在对话中描述研究任务；工具记录结果后，页面随之更新。

六个任务模板覆盖文献综述、选题与查新、实验分析、写作与润色、绘图和审稿。选择入口会显示可复制到对话中编辑的请求，不会直接启动模型请求。证据条目显示保存的摘录和阅读深度，并明确标注支持程度是作者的判断。

项目、成果和缓存阅读按钮通过常规会话文件预览打开已记录的路径。论文链接仅打开有效的 HTTP(S) 地址。失败的文献来源在返回结果旁保留诊断信息。仅获取摘要的阅读结果始终标注为“仅摘要”。

按名称、描述、来源、许可证或要求搜索技能。已检查的科研条目展示宿主提供的可用状态。在科研工具尚未返回结果时，现有技能目录提供指引条目；这些条目明确标注依赖尚未检查。目录读取失败时保留已有条目并提供重试。会话预设变化或连接重置会清空目录。

<a id="understand-the-implementation"></a>
## 理解实现

插件在现有侧边栏键控插槽中注册 `science` 页面类型、正文和标题。框架钩子读取 `science` 投影、会话生命周期、工作目录和目录可观测值。组件不包含外部订阅逻辑，页面不创建会话事件。Node 入口仅为空的插件名册入口。

用量来自 `ScienceMetrics`：已结算请求、提供商计量项、缓存读取占比、累计响应时间、首次可见响应与估算费用。缺失的计量项、延迟或费用显示为不可用或未知，不以零代替。插件不计算定价，也不从估算值推断缓存命中。

<a id="model-experience"></a>
## 模型体验

无直接影响。本插件不注册模型工具，也不提交提示词；已记录的研究操作由宿主科研工具负责。

#### KV Cache 影响

无。浏览、筛选和打开已记录文件不会改变请求前缀，也不调用模型。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- 页面展示最新持久化科研状态，不包含未记录的文件系统编辑。
- 指引目录中存在某项技能不代表依赖已就绪；可在对话中要求检查科研技能，查看详细分类。
- 提供商的计量值可能仍不可用，估算费用需要已知的定价和币种。
