# Template selection reference

Select the journal and article type from user scope and available evidence. The illustrated-paper default is a full-width title and a genuine two-column body with edge floats; when unspecified, use `neutral` and continue autonomously. A specific journal requirement can replace that default. Load the [bundled ARIS/Nature/Scholar workflow](upstream-workflow.md) automatically for planning, drafting and review; a custom class alone is not the writing workflow.

| CLI choice | Source and purpose | Required template-specific resources |
| --- | --- | --- |
| `neutral` | First-party two-column `article`, full-width title, compact headings, 6 mm gutter and serif text | Standard article, geometry, caption and titlesec |
| `nature-inspired` | The same two-column structure with restrained editorial headings and an explicit unofficial label | Neutral resources; no Nature branding, official class or endorsement |
| `ieee` | Installed `IEEEtran` journal class, numeric cite and IEEE bibliography; class-owned margins and column geometry | IEEEtran.cls, IEEEtran.bst, cite.sty and the class's Times font resources |

All templates use actual LaTeX with `amsmath`, `amssymb`, `booktabs`, `siunitx`, `graphicx`, `xcolor` and `hyperref`. Chinese and bilingual text require XeLaTeX, `ctex` and either Windows CJK fonts (`--cjk-fontset windows`, default on Windows) or Fandol (`--cjk-fontset fandol`, default elsewhere). Generated source names the selected font set explicitly; moving a project to another platform may require changing that source and another compile/render check. English defaults to pdfLaTeX. The local dependency probe and actual build determine readiness; installed executable names alone do not prove package/font availability.

IEEE directs authors to its publication-specific selector and author tools. The helper uses the installed class without redistributing an unofficial replacement. Select the journal's actual options and author metadata before submission; generated `IEEEtran` syntax is not a promise of conformance to every IEEE venue. [IEEE article templates](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/tools-for-ieee-authors/ieee-article-templates/) and [author tools](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/) checked 2026-10-18.

Narrow `figure` and `table` environments must explicitly use `[t]`, `[b]`, `[tb]` or their `!` variants. Wide `figure*` and `table*` use `[!t]`; stock two-column LaTeX does not provide bottom-wide placement. No inline `[h]`/`[H]`, unconstrained default placement or `[p]` is accepted by this helper. The source checker enforces these choices after author edits. Generated floats remain top-aligned even if a late float is flushed onto a separate page. A venue needing bottom-wide floats must use a compatible, separately tested output routine outside this helper's default. Insert floats near their first reference and give the output routine enough following text; inspect actual page coordinates and renders to avoid a float backlog and avoidable blank pages.

The `--layout-demo` initialization option produces an illustrated multi-page stress fixture: six vector figures, two tables, aligned equations, early/late cross-references and optional CJK paragraphs. All data and prose are explicitly demonstration material. It tests page flow; it is not a model-quality benchmark or a real research paper. Ordinary initialization retains unknown evidence markers instead of inventing this content.

Nature does not require a generic imitation of its published page layout for an initial manuscript. The `nature-inspired` draft is explicitly unofficial. Check its actual article type and reporting requirements, figure specifications and bibliography instructions before submission. [Nature formatting guide](https://www.nature.com/nature/for-authors/formatting-guide) checked 2026-10-18.

Springer Nature provides its own authoring package and documentation, including `sn-jnl.cls`; this recipe links to the official source rather than bundling a guessed class or claiming it is installed. For a Springer target, obtain the appropriate official package through an approved dependency workflow, retain its license and release metadata, then adapt the editable project or use the venue's documented build. This CLI does not currently scaffold `sn-jnl`'s distinct author/abstract macros. [Springer Nature LaTeX author support](https://www.springernature.com/de/authors/campaigns/latex-author-support) and [template support](https://support.springernature.com/en/support/solutions/articles/6000250920-latex-template-package-for-article-book-submissions) checked 2026-10-18.
