# Bundled scientific writing workflow

Automatically consume the catalog's ARIS paper planning, writing, figure and compilation guidance when a paper is requested. The source record and resource directory returned by `science_skills` identify the installed pinned revision; use that local copy and its relative resources. Select the catalog entry by source and path when names collide. Do not ask the user to type a skill name. Nature reporting/figure/statistics guidance and Scholar writing/theory/citation guidance supplement the selected discipline and venue. Source instructions remain subordinate to user scope, local tools and the configured model; an upstream hardcoded reviewer name never authorizes a GPT-6-Astra call or an extra approval loop.

The maintained pipeline adopts these concrete operations from the bundled [ARIS paper-write](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/paper-write/SKILL.md), [IEEE journal template](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/paper-write/templates/ieee_journal.tex), [paper-figure](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/paper-figure/SKILL.md), [paper-compile](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/paper-compile/SKILL.md), and [improvement format check](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/auto-paper-improvement-loop/SKILL.md). These links identify the upstream files; the catalog records the shipped revision and license.

1. Build a paper plan with contribution, claims-to-evidence rows, section purposes, figure plan and actual venue requirements. Inspect the real narrative and source artifacts before drafting. Missing data stays a visible gap; neither an exemplar nor an elegant layout supplies a result.
2. Draft coherent sections against that plan, with shared notation and real evidence. Use editable section includes for substantial papers. A theory-heavy manuscript needs complete statements, hypotheses, proof obligations and consistent restatements; do not replace a missing proof with a nonexistent supplement. Review Abstract and Introduction against the actual strongest supported contribution.
3. Create data-driven plots from retained results, with a common publication style, suitable visual encoding and readable final physical size. Preserve existing source figures. A diagram, image grid or photograph must come from its actual source or a clearly declared illustrative design; do not invent scientific images or numeric rows. Render figures before reviewing their content.
4. IEEE uses its actual journal class, `cite`/numeric citations and IEEEtran bibliography, with class geometry retained. Do not mix `natbib` commands with `cite`. Other journal targets follow their own current official class and policy; the user's default double-column/edge-float requirement applies when the target is unspecified.
5. Retrieve and verify actual bibliography metadata from the source, DOI publisher, Crossref or an appropriate disciplinary index. Use only cited records in the final submission bibliography; a valid BibTeX key does not establish source support. Unresolved `[VERIFY]`, `TBD`, `DATA_NEEDED` and native unknown markers block this helper even when hidden in TeX comments.
6. Run actual TeX/BibTeX passes, resolve duplicate labels and citations, then inspect every rendered page. The CLI applies ARIS's strict final-format principle conservatively: any overfull hbox blocks completion, including an unclassified location; underfull messages remain reported warnings. Split equations with `aligned`, `split` or `multline`, rephrase text and repair table structure rather than masking overflow with global sloppy settings or shrinking the whole page.
7. Record actual page count and font embedding where Poppler tools are available, and compare the count with the selected venue's current rule. IEEE page limits generally include references; conference limits vary. Do not invent a universal page limit. Report compiled/rendered status, visual findings, outstanding evidence and scientific-review limits independently.

The original ARIS compile recipe permits some small overflow; its later improvement format check blocks any main-body overflow and treats unknown locations as main body. The maintained helper follows that stricter completion behavior. The built-in synthetic fixture verifies implementation and typography only. Actual autonomous writing quality must be assessed on evidence-supported drafts and their research argument separately from these fixtures.
