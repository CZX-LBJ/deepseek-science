# Scientific figures, equations and claims

## Figures

Use editable vector PDF for LaTeX inclusion, with SVG and generating code retained for diagrams, curves and statistical plots. Microscopy, photographs and other inherently raster data remain honest raster images at the target venue's required resolution; do not trace data or invent resolution. Keep raw data separate from presentation exports. Supply uncropped originals, scale bars, acquisition details and documented image processing when relevant.

Use 90 mm and 180 mm as convenient generic single/double-width working sizes; adjust to the selected venue before submission. Nature's general formatting page lists 90/180 mm, while its current figure guide and final-submission page list 89/183 mm. These are distinct published specifications, not interchangeable guarantees. Choose the target journal's current requirement and inspect at the final physical size. [Nature formatting guide](https://www.nature.com/nature/for-authors/formatting-guide), [Nature figure export guide](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/), and [final submission](https://www.nature.com/nature/for-authors/final-submission) were checked on 2026-10-18.

The included `plot_figure.py` produces paired PDF/SVG exports from a `group,value` CSV. Run `python plot_figure.py --input measurements.csv --output figures --width-mm 90 --unit mV --xlabel Treatment --ylabel "Voltage (mV)"` into a directory without those figure names. The helper plots individual rows, means and sample SD (`ddof=1`) and requires at least two finite values per group. Its publication mode has no in-plot title by default; use the manuscript caption, or pass an explicit `--title` when appropriate. `--font-family serif` is the ARIS/IEEE-oriented default; `sans` supports Nature figure guidance. Initialization selects the corresponding family for its template. Only explicit `--demo` adds an invented-data heading. Each row must be an independent sampling unit for an independent-unit interpretation; paired, clustered and repeated designs need their own model and figure. The helper does not infer a study design.

At final size, use readable embedded fonts, restrained line weights, clear panel labels and consistent units. The example uses editable SVG text, embedded TrueType PDF fonts and an accessible blue/orange-first palette with redundant marker shapes. Colour alone must never encode the conclusion. Place narrow figures/tables at column tops/bottoms using explicit `[t]`/`[b]`/`[tb]`; wide floats use `[!t]`. Do not interrupt paragraphs with `[h]`/`[H]`, shrink the entire page or manually insert blank space to resolve a queue. Avoid misleading axis truncation, decorative 3D, piecing separate experiments together without disclosure or smooth curves unsupported by measurements. A chart export being vector does not establish readability; inspect the actual rendered page.

Every statistical legend must state the exact independent-unit count per group, what each dot represents, the centre statistic and exact error definition (SD, SEM, confidence/credible interval with level and computation). Report missing data, exclusions, normalization, pairing, replicates and tests with their assumptions as applicable. Do not label rows as biological replicates unless that is true. A representative image needs its selection rule and independent experiment count; it does not replace quantitative uncertainty. Equations, tables and figure values must agree with the retained analysis outputs and claim register.

## Mathematics and units

Use `amsmath` environments, named equation labels and cross-references. Define every symbol, index, domain, random quantity, estimator and assumption near first use. Distinguish definitions, conjectures, model assumptions, approximations, derivations and proved statements. State units and dimensional consistency; use `siunitx` for quantities and SI units when available. Keep vectors, tensors, operators and scalar variables visually consistent with the discipline. Number equations that are referenced; align derivations without embedding screenshots of formulas.

For statistical estimands, specify the population, sampling unit and dependence structure; distinguish sample size from repeated measurements and technical replicates. Label standard deviation, standard error and uncertainty intervals explicitly. For physical or engineering models, define initial/boundary conditions, approximations, parameter ranges, numerical solver and convergence/error checks. For mathematical work, verify proof obligations, quantifiers and exceptional cases. For chemistry and biology, preserve reaction conditions, stoichiometry, identifiers and nomenclature. For clinical work, tie numerical claims to the actual cohort and prespecified/exploratory status; formatting never creates ethical approval or diagnostic evidence.

## Claim register

Use the existing evidence fields `claim,artifact,locator,quote,support,depth,citation_status` in `claims.csv`. Every quantitative, comparative and causal assertion needs an actual source row or artifact locator. A bibliography key only links a record; it does not establish that the source supports the sentence. Check the source itself at the recorded reading depth, its bibliographic metadata and the corresponding analysis. Retain unknown markers while drafting; a deliverable may explicitly list unfinished work, but this CLI intentionally refuses to certify an unresolved scaffold as a compiled publication project. Do not replace unknown markers with plausible invented content.
