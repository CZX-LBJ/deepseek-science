# Descriptive analysis method

This helper summarizes observed rows without testing hypotheses. N is the number of admitted CSV rows in a group. The arithmetic mean is their sum divided by N. Sample SD uses the sum of squared deviations divided by N-1, then the square root. SD and the confidence interval are unavailable for N=1; blank summary cells and JSON nulls preserve that distinction from zero.

The 95% interval uses a percentile bootstrap of the group mean. For each group in sorted label order, a local pseudorandom generator initialized by `--seed` samples N rows with replacement for each resample. Sorted bootstrap means are evaluated at probabilities 0.025 and 0.975 using linear interpolation at index `(B-1)*p`, where B is `--bootstrap-resamples` (default 2,000). This is an approximate interval under independent, identically distributed row sampling within a group. It has no guaranteed coverage for a particular small or biased sample; constant observations yield a zero-width empirical interval without establishing population certainty. The helper performs no multiplicity correction, pairing, clustering adjustment, model fitting or significance test.

Before interpretation, identify the independent sampling unit and how it entered the study. Aggregate technical replicates only using a justified prespecified rule, or choose a model that handles their dependence. Repeated measures and subjects shared across groups need their joint sampling structure retained. Group mean differences remain descriptive unless a suitable design and analysis justify stronger conclusions.

`metadata.json` records exact input and script SHA-256 hashes, parameters, Python/matplotlib versions, interval method, group summaries and assumptions. `input.csv` preserves the original bytes; `analyze_csv.py` preserves the executed helper. Rerun those copies with the same seed and resample count. Figure bytes are reproducible within the same Python/matplotlib environment; versions, fonts and rendering backends may change them across environments. Points show admitted rows, squares show means and vertical lines show available bootstrap intervals. `observations.csv` retains each source row number.
